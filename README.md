# Finance Tracker
A personal finance tracker built with HTML, CSS and JavaScript

## About the project
The project is a web-based finance tracker designed to help users keep track of their income and expenses.
The project is also being developed as a part of my journey learning web development.

# Features:
- Add income and expenses
- Record transaction descriptions
- Categorise transactions
- Track transaction dates
- Edit transactions
- Delete transactions
- View transaction history
- Calculate income, expenses and balance
- Store transaction data locally

## Technologies

- HTML
- CSS
- JavaScript
